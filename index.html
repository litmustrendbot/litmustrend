How the Strategy Operates

A completely rule-based, non-discretionary SMC algorithm that removes emotional interference.

01
📊

Previous Day Close (PDC) Bias

At daily rollover (00:00), the anchor level is set. If price is above the PDC line (2px solid black), only Bullish Longs are permitted. If below, only Bearish Shorts are taken.

02
⚡

5M Internal Swing Fractals

Uses a 3-bar left and 3-bar right fractal lookback. A Break of Structure (BOS) is confirmed strictly when a 5M candle closes beyond the swing point and the initiating impulse extreme.

03
🎯

Fair Value Gap (FVG) Refinement

Scans the breakout leg for 3-bar imbalances. If an FVG forms, entry is refined to the gap edge with a pending limit order. If a fresh BOS forms before fill, older setups are discarded instantly.

04
🛡️

Stepped Trailing (9.5R - 9.9R)

Trades run freely without premature break-even choking. Once floating profit hits +9.5R, the trailing stop steps dynamically (+5R, +6R, +7R, +8R, +9R) until full 1:10 TP execution.
